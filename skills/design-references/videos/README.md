# Video references

Walkthrough videos Hasan likes. Use them as inspiration, not templates.

## Chalk #248 walkthrough

`chalk-248-walkthrough.mp4` explains Chalk PR #248 (the lean cut that removed accounts and board uploads) in 1 min 59 s. `chalk-248-walkthrough.sheet.png` shows each slide as it ends, so you can see the whole video without playing it.

- It is a run of still slides on the warm off-white background: a small header with the PR name and a beat counter, a bold heading, and plain rows under it.
- Each beat has one spoken line, and a dark caption bar at the bottom shows the same words, so it still works with the sound off.
- Before and after reads at a glance: rows that stay are plain, removed rows are red and struck through, and added rows are green, sometimes with a short grey note.
- It ends with the calls the reader has to make, then how sure the change is: what was checked, what wasn't, and how to undo it.
- The voice is Kokoro `af_heart`, run locally, and every line is written like a person explaining the change out loud.
